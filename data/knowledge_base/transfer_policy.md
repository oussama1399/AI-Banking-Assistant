# transfer_policy.md
## Politique des virements

### Virement National (Domestique)
- Délai : 24h ouvrées.
- Frais : Gratuit pour les particuliers.
- Montant max : 1 000 000 MAD.

### Virement Instantané (Maroc)
- Délai : < 20 secondes.
- Frais : 5 MAD par virement.
- Montant max : 150 000 MAD.
- Disponible 24h/24, 7j/7.

### Motifs de rejet courants
| Code | Motif | Action |
|------|-------|--------|
| INSUFF_BALANCE | Solde insuffisant | Approvisionner le compte |
| INVALID_RIB | RIB invalide | Vérifier le RIB du bénéficiaire |
| ACCOUNT_BLOCKED | Compte bloqué | Contacter le support |
| LIMIT_EXCEEDED | Plafond dépassé | Réduire le montant |
